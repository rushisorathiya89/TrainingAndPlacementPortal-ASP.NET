# 🎓 RK University — Training & Placement Portal
 
An official web-based Training & Placement management system developed for **RK University**, built using **ASP.NET**. This portal is designed and developed in accordance with RK University's placement rules, regulations, and internal processes to digitize and streamline the entire campus recruitment workflow.
 
---
 
## 🏫 About RK University T&P Portal
 
The RK University Training & Placement Cell manages campus recruitments for hundreds of students every year. This portal was built to replace manual processes with a centralized digital system that follows the university's official placement policies — ensuring transparency, efficiency, and a smooth experience for students, recruiters, and placement officers alike.
 
---
 
## ✅ Key Features
 
- 🧑‍🎓 **Student Registration & Profile** — Students can register, fill academic details, and maintain their placement profile as per university eligibility norms
- 🏢 **Company & Recruiter Management** — Companies visiting campus can be registered and managed centrally
- 📋 **Eligibility Screening** — Automatic eligibility checks based on RK University's criteria (CGPA, backlogs, attendance, etc.)
- 📅 **Drive Scheduling** — Schedule and announce placement drives, pre-placement talks, and interview rounds
- 📝 **Job Applications** — Students can apply for drives they are eligible for
- 📊 **Placement Records** — Track offer letters, CTC, and final placement status
- 🔐 **Role-Based Access** — Separate dashboards for Admin/TPO, Students, and Company Representatives
- 📢 **Notices & Announcements** — TPO can broadcast placement-related notices to all students

## 🛠️ Tech Stack
 
| Technology | Purpose |
|---|---|
| ASP.NET MVC | Backend & Server-side Logic (Model-View-Controller Pattern) |
| Entity Framework | ORM — Database Access & Data Modelling |
| C# | Business Logic & Rules Implementation |
| Razor Views (.cshtml) | UI Templating & Page Structure |
| HTML / CSS | Frontend Markup & Styling |
| JavaScript | Client-side Validation & Interactivity |
| SQL Server | Relational Database |
 
---
 
## 👤 User Roles
 
| Role | Description |
|---|---|
| **Admin / TPO** | Full control — manages students, companies, drives, eligibility, and reports |
| **Student** | Registers, views eligible drives, applies, and tracks placement status |
| **Company / Recruiter** | Posts job requirements, views shortlisted applicants, updates results |
